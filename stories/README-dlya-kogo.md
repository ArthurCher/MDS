# Сторис: Для кого это

Готовый слайд для Instagram Stories (1080×1920).

## Файлы для публикации

- `dlya-kogo.jpg` — удобнее для Stories
- `dlya-kogo.png` — максимальное качество

## Что на слайде

- **Шрифты и написание как у тарифа «План»:** Oranienbaum (заголовки секций) + Montserrat ALL CAPS, стрелки `→`/`←`, rule-линии, CTA
- **Палитра Coolors** `177ae3-9b3441-b355eb-ab6d78-25c5df` — все 5 цветов в акцентах, чекбоксах, градиентах и нижней полосе
- **Композиция:** Артур справа (как девушка на B&W-референсе), крупный cutout без фона, cool-дуотон под палитру; текст поверх с полупрозрачными карточками
- **3 блока контента** как в брифе

## Контент

1. Если вы узнаёте себя хотя бы в одном пункте
2. 6 пунктов (дубликат «Лишний вес…» убран)
3. Не «для идеальных». Для реальных людей с реальной физиологией

## Пересборка PNG

```bash
google-chrome --headless=new --no-sandbox --disable-gpu \
  --user-data-dir=/tmp/chrome-story \
  --hide-scrollbars --window-size=1080,1920 \
  --virtual-time-budget=5000 \
  --screenshot="$PWD/dlya-kogo.png" \
  "file://$PWD/dlya-kogo.html"
```
