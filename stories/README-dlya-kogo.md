# Сторис: Для кого это

Готовый слайд для Instagram Stories (1080×1920).

## Файлы для публикации

- `dlya-kogo.jpg` — удобнее для Stories
- `dlya-kogo.png` — максимальное качество

## Что на слайде

- **Светлый студийный бело-серый фон** (как B&W-референс с девушкой) — без синего, без неона, без тёмного киберпанка
- **Строгий монохром:** чёрный / белый / серый
- **Шрифты и рамки как у тарифа «План»:** Oranienbaum + Montserrat CAPS, тонкие скруглённые рамки, стрелки, CTA — адаптированы под светлый фон
- **Артур:** фон убран, B&W с мягким светом, корпус / по пояс справа; текст читаемый поверх

## Контент

1. Узнаёте себя — если узнаёте себя хотя бы в одном пункте
2. 6 пунктов списка
3. Главное — не «для идеальных». Для реальных людей с реальной физиологией
4. CTA: Напиши в директ

## Пересборка PNG

```bash
google-chrome --headless=new --no-sandbox --disable-gpu \
  --user-data-dir=/tmp/chrome-story \
  --hide-scrollbars --window-size=1080,1920 \
  --virtual-time-budget=5000 \
  --screenshot="$PWD/dlya-kogo.png" \
  "file://$PWD/dlya-kogo.html"
```
