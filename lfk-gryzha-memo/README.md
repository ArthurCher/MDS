# Памятка: ЛФК при пояснично-крестцовой грыже

Премиальная **5-страничная** домашняя памятка (A4) для Артура Черемисина.

## PDF

`LFK-gryzha-pamyatka.pdf`

Открыть в браузере: `index.html` → «Скачать PDF».

## Структура

1. Правила + анатомия  
2. Блок 3 — вытяжение у стены (вверх / правый бок / левый бок)  
3. Блоки 4–5 — разгрузка со стулом + декомпрессия в проёме  
4. Блоки 6–7 — кошка–корова (3 кадра) + вытяжение сидя на пятках (2 кадра)  
5. Блок 8 — растяжение ягодицы и поясницы + контакты  

## Визуал

- единый стиль: синяя кепка, носки со смайлами, домашний фон  
- важные моменты выделены красным  
- повторения и время — бирюзовым  

## Сборка PDF

```bash
google-chrome --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=LFK-gryzha-pamyatka.pdf \
  "file://$(pwd)/index.html"
```
