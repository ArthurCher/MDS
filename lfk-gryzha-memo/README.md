# Памятка: ЛФК при пояснично-крестцовой грыже

Премиальная **5-страничная** домашняя памятка (A4) для Артура Черемисина.

## PDF

`LFK-gryzha-pamyatka.pdf`

Открыть в браузере: `index.html` → «Скачать PDF».

## Структура

1. Правила + анатомия  
2. **Блок 1** — вытяжение у стены (правый / левый бок)  
3. **Блок 2–3** — разгрузка со стулом + декомпрессия в проёме  
4. **Блок 4–5** — мобилизация на четвереньках + вытяжение сидя на пятках  
5. **Блок 6** — растяжение ягодицы и поясницы + контакты  

## Визуал

- единый стиль: синяя кепка, носки со смайлами, один коврик, домашний фон  
- важные моменты — красным; повторения и время — бирюзовым  

## Сборка PDF

```bash
google-chrome --headless=new --disable-gpu --no-pdf-header-footer \
  --virtual-time-budget=15000 \
  --print-to-pdf=LFK-gryzha-pamyatka.pdf \
  "file://$(pwd)/index.html"
```
