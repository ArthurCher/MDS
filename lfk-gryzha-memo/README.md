# Памятка: ЛФК при пояснично-крестцовой грыже

Готовый визуальный гайд для отправки клиенту после лид-магнита.

## Что внутри

- `index.html` — памятка с блочной структурой и иллюстрациями
- `styles.css` — визуальный стиль (forest + signal red)

## Содержание блоков

1. **Важно** — когда начинать, запрет нагрузки на поясницу, ежедневная рутина, отказ от классического массажа
2. **Блок 01** — разогрев и вытяжение у стены
3. **Блок 02** — вытяжение со стулом (5–7 повт., 5–10 сек)
4. **Блок 03** — вытяжение в дверном проёме (5–7 повт.)
5. **Блок 04** — скручивание лёжа на ягодицы/поясницу (5–7 на сторону)

Контент собран из транскрипта методики Artur Cheremisin.

## Как открыть / отправить

1. Откройте `index.html` в браузере
2. Нажмите **«Скачать / Печать PDF»** → сохраните как PDF
3. Отправьте PDF клиенту

Или разместите папку на хостинге и отдавайте ссылку.
