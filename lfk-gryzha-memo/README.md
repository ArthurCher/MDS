# Памятка: ЛФК при пояснично-крестцовой грыже

Премиальная **4-страничная** домашняя памятка (A4).

## PDF

`LFK-gryzha-pamyatka.pdf`

## Структура

1. Правила + анатомия  
2. Блок 3 — разогрев у стены  
3. Блоки 4–5 — стул + дверной проём  
4. Блок 6 — скручивание лёжа + итог  

## Визуал

- фото реального человека (старт / низ)
- штриховая амплитуда движения
- важные моменты выделены красным
- повторения и время — бирюзовым

Дверной проём: бок к одному косяку, руки в противоположный, опускание за счёт рук (по методике транскрипта).
