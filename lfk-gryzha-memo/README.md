# Памятка: ЛФК при пояснично-крестцовой грыже

Компактный гайд на **3 страницы A4** для отправки клиенту после лид-магнита.

## Файлы

- `LFK-gryzha-pamyatka.pdf` — готовый PDF
- `index.html` + `styles.css` — исходник (можно править и снова печатать)

## Что внутри

1. Правила старта + карта мышц (поясница / ягодицы / длинные спины)
2. Упр. 1 — разогрев у стены (3 позы)
3. Упр. 2–3 — стул и дверной проём (по 3 позы)
4. Упр. 4 — скручивание лёжа + легенда цветов + итог

На схемах: поэтапность поз и цветное выделение рабочей зоны.

## Как пересобрать PDF

Открой `index.html` в Chrome → «Скачать PDF» / Print → Save as PDF.
