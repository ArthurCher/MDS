# Памятка: ЛФК при пояснично-крестцовой грыже

Премиальная **2-страничная** домашняя памятка для клиента после лид-магнита.

## Скачать

`LFK-gryzha-pamyatka.pdf`

## Состав

**Страница 1**
- Правила и подготовка
- Анатомия работы (иллюстрация спины с акцентами)
- Разогрев у стены (фото реального человека)

**Страница 2**
- Декомпрессия со стулом
- Вытяжение в дверном проёме
- Скручивание лёжа
- Итог + @a.cheremisin_fitness

## Исходники

- `index.html` / `styles.css` — вёрстка под печать A4
- `assets/img/` — фото и анатомическая иллюстрация

Открой `index.html` в Chrome → «Скачать PDF».
